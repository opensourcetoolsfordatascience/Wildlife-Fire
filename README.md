### Project Overview
This project uses Machine Learning (Random Forest Classifier) to predict wildfire risks based on meteorological data.

### Tech Stack
* **Environment:** Google Colab
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, Random Forest, Matplotlib
* **Dataset:** Forest Fires Data Set (UCI/Kaggle)
